# 角色模型工作台

从“启动角色工作台.cmd”打开，选择游戏目录并扫描。选中模型后自动读取该模型、贴图和顶点布局，加载成功后即可调整和应用。

- 整体宽度：兼容 MDL v4 模型；0 保留原版，−500 对应 75% 宽度，1000 对应 150% 宽度。
- 进度条旁的“还原原模型”会把当前强度一键归零，预览立即回到原模型位置；它不会安装或修改游戏文件。
- 胸部／胸廓：优先使用完整骨骼，缺失单侧末端时检查对称关系；无完整胸部骨骼时根据脊柱、颈部、蒙皮权重与前侧表面自动定位。估计定位会明确标注。衣服和皮肤共享变形场，极端强度的位移按各模型自动约束。年龄资格与骨骼检测独立显示：目录明确标记的未成年禁用；从游戏原始模型归档扫描到、但目录尚未登记的默认角色按成年处理；其他未知来源仍显示年龄资料不足。年龄资料详见 assets/character-ages.json，前端与导出使用同一规则。鼠标悬停角色详情可查看依据与来源。
- 没有可靠骨骼、布局不支持时会报错；缺少贴图时提示并显示灰色。扫描列表可能包含游戏未使用的资源，不代表全部能在游戏中出场。
- “应用到游戏”会备份后安装，必须先退出游戏；原始 PAC 只读。应用其他角色不会重置雪拉扎德的已安装模型。
- 每次“应用到游戏”同时把 F8 召唤目标设为此次安装的角色。进入可自由移动的场景按 F8；F9 切换原版／调整后，再按 F8 重建测试角色。仅在工作台切换下拉框而未安装，不会改变游戏目标。召唤的是临时测试角色，不会加入队伍。

已完成多角色离线加载、WPF 选择/滑条/渲染、预览与导出顶点一致性检查。通用变形的骨骼动画和服装在游戏内的表现尚未逐角色实测。

开发：publish.ps1 输出 dist-summon。tools/auto_model.py 依赖同工作区 Sky1st-Scherazard-Mod/vendor 解析器和 Python 环境，尚非独立发行包。

开发者打包：在项目根目录双击 `BuildRelease.cmd`，或运行 `powershell -ExecutionPolicy Bypass -File .\build-release.ps1`。脚本会先从 `assets\Sky1stCharacterStudio.png` 自动生成多尺寸 EXE 图标，然后还原并发布自包含 win-x64 工作台、重新编译 DAT 构建器和两个原生插件、按白名单组装便携目录、检查目录中没有模型/PAC 等游戏资源，再生成 `release-artifacts\Sky1stCharacterStudio-<版本>-win-x64.zip` 及同名 `.sha256`。如果 `game-directory.txt` 指向可用的游戏目录，还会运行不启动游戏的 WPF/导出/安装回滚离线检查；没有游戏目录时只跳过这一项。`-SkipSmoke` 可跳过离线检查，`-KeepStaging` 可保留本次 `release-stage\pack-*` 临时目录以便审阅。

角色名字自动从所选游戏目录的 table_sc/t_name.tbl 读取（缺少时回退繁中、韩文表）；一个模型对应多个名字时合并显示。未登记模型保留编号。骨骼检测独立于成年资格，支持 Breast/Bust/Mune 及常见左右、末端命名；没有完整末端时使用蒙皮表面估计；定位依据不足时禁用，不强行套用其他角色的参数。

2026-09-10 年龄策略更新：目录登记 54 个成年模型、15 个未成年模型；目录中的明确标记始终优先。游戏原始模型归档中新扫描到、但目录尚未登记的默认角色按成年处理；未经过原始归档扫描的未知 ID 仍保留“年龄资料不足”。
